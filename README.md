# EPL Data Analysis Using Python

## Project Overview
This project analyzes English Premier League (EPL) match data using Python to explore team performance, goal-scoring trends, home advantage, and match statistics.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn

## Analysis Performed
- Team wins, goals, and points
- Home vs. away performance
- Common match scorelines
- Relationship between shots and goals
- Season-wise goal-scoring trends
- Half-time vs. full-time results

## Visualizations
Bar charts, pie charts, histograms, box plots, scatter plots, and heatmaps.

## Conclusion
This project uses data analysis and visualization to identify EPL performance patterns and gain insights into historical football matches.
